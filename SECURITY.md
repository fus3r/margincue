# Security

Please don't report a security problem in a public issue.

Open a new issue titled "Security contact" without any details, and I'll reply with a private way to send them.

MarginCue runs on your machine and has no server of its own. In Claude Code, readings go to Claude through your own session; in Codex, through your own Codex login. The code in this repository is the whole surface: the Claude Code mod in `mods/claude-code`, the Codex plugin and launcher in `mods/codex`, and the terminal relay in `crates/margincue-relay`.
